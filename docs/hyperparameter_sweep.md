# انتخاب وزن‌های SupCon و DC

وزن‌ها فقط روی **Dev همان Track 1** انتخاب شدند (هیچ‌گاه روی Test). همهٔ اجراها
با تنظیمات یکسان: `xlm-roberta-base`، `lr=2e-5`، `batch=16`، `max_length=64`،
`epochs=5`، `seed=42`.

| تنظیم | Weighted F1 | SoftCons | HardCons |
|---|---|---|---|
| Baseline (CE) | 0.6905 | 0.7978 | 0.7040 |
| CE + SupCon، λ=0.1 | 0.6653 | 0.7834 | 0.6787 |
| CE + SupCon، λ=0.05 | **0.6996** | **0.8303** | **0.7256** |
| CE + SupCon، λ=0.03 | 0.7001 | 0.8267 | 0.7220 |
| CE + DC، λ=0.1 | 0.6832 | 0.8123 | 0.6968 |
| CE + DC، λ=0.05 | 0.6874 | 0.8195 | 0.7184 |
| CE + DC، λ=0.03 | 0.6687 | 0.8159 | 0.7040 |
| CE + SupCon + DC، 0.05/0.05 | 0.6914 | 0.8051 | 0.7148 |

نتیجه‌گیری:

* `λ=0.1` برای SupCon روی این داده (۳۰۴۲ نمونه، ۵ اپوک) زیادی است و همگرایی را
  کند می‌کند؛ `0.05` هم بهبود F1 و هم بهبود دو معیار سازگاری می‌دهد.
* `0.03` از نظر F1 تقریباً برابر `0.05` است ولی سازگاری کمتری دارد، پس `0.05`
  انتخاب شد.
* DC به‌تنهایی در `0.05` بهترین نتیجه را دارد؛ `0.03` و `0.1` هر دو بدترند.
* ترکیب کامل با `0.05/0.05` از Baseline بهتر است اما از SupCon تنها کمی عقب
  می‌ماند؛ این یک یافتهٔ واقعی Ablation است و در گزارش نهایی همان‌طور که هست
  گزارش می‌شود (بدون دست‌کاری روی Dev).

این جدول در `outputs_tune/` (اجرای جداگانه) تولید شده است تا نتایج اصلی در
`outputs/` با وزن‌های نهایی دوباره و مستقل ساخته شوند.
